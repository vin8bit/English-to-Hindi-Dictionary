English to हिन्दी Dictionary project

JDK 8
This project built in netbeans 8.2


## Project Description

- This dictionary allows users to translate common English words into Hindi.  
- It features a user-friendly GUI built with Java Swing.  
- The application is suitable for beginners learning Java and interested in language tools.  
- Words and meanings are stored in a local database or file (as per implementation).  
- Can be extended further with features like pronunciation, examples, or speech input.
